# CHUAN-DI (ชวนดิ!)

เวลาจะนัดเพื่อนไปกินข้าวหรือไปเที่ยวทีไร ชอบลืมทุกทีว่าใครแพ้อาหารทะเล ใครไม่กินหมู ใครชอบร้านแนวไหน แล้วก็ต้องมานั่งไล่ถามในแชทกันใหม่ตลอดว่าวันไหนว่างตรงกันบ้าง

**ชวนดิ!** เลยทำขึ้นมาไว้ช่วยจัดการเรื่องพวกนี้ให้ง่ายขึ้น เก็บข้อมูลความชอบของกลุ่มเพื่อน หาวันว่างที่ตรงกัน และสร้างนัดส่งลิงก์ให้เพื่อนกดตอบรับได้ในที่เดียว

---

## ลองเปิดใช้งานบนเครื่อง

ต้องมี **Node.js เวอร์ชัน 22 ขึ้นไป** อยู่ในเครื่องก่อน จากนั้นเปิดโฟลเดอร์นี้ใน Terminal แล้วรัน:

```bash
npm install
npm run dev
```

เสร็จแล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:3000` ได้เลย

- **บัญชีทดลองสำหรับลองเล่น:** อีเมล `demo@chuan-di.app` / รหัสผ่าน `ChuanDiDemo123` (ในหน้าเข้าสู่ระบบมีปุ่มกดเข้าบัญชีทดลองให้เลย ข้างในมีเพื่อนตัวอย่าง 22 คน กิจกรรม และตารางวันว่างจำลองใส่ไว้ให้แล้ว)
- **ถ้าอยากลองเชื่อม Google Calendar จริง:** คัดลอกไฟล์ `.env.example` ไปเป็น `.env.local` แล้วตั้งค่าตามขั้นตอนใน [docs/GOOGLE_CALENDAR_SETUP.md](docs/GOOGLE_CALENDAR_SETUP.md) (ถ้าไม่ตั้งค่าก็ยังเข้าใช้งานทุกหน้าและกรอกวันว่างเองได้ตามปกติ)

## วิธีใช้งานแบบง่าย ๆ

### 1. ใส่ข้อมูลของตัวเองก่อน (`โปรไฟล์ฉัน`)
เริ่มจากเข้าไปกรอกข้อมูลของตัวเองก่อนว่าชอบกินอะไร ชอบเที่ยวแบบไหน รวมถึงข้อจำกัดด้านอาหาร เช่น แพ้อาหารทะเล ไม่กินหมู กินฮาลาล หรือมังสวิรัติ พอเซฟไว้แล้ว เวลาเราไปแอดเพื่อนกับคนอื่นในแอป เพื่อนก็จะเห็นข้อมูลตรงนี้ของเราเลย ไม่ต้องคอยทักมาถามซ้ำเวลาจะเลือกร้าน

### 2. เพิ่มเพื่อนเข้ามาไว้ด้วยกัน (`แอดเพื่อน` / `เพื่อนของฉัน`)
- กดปุ่ม **แอดเพื่อน** ด้านบน แล้วพิมพ์อีเมลของเพื่อนที่ใช้แอปนี้เหมือนกันเพื่อส่งคำขอเป็นเพื่อน
- ถ้ามีใครส่งคำขอมาหาเรา ก็เข้าไปกดรับได้ที่หน้า **เพื่อนของฉัน**
- พอเชื่อมเป็นเพื่อนกันแล้ว ความชอบและข้อจำกัดของเพื่อนจะลิงก์มาให้ดูอัตโนมัติ โดยเราไปแก้ไขข้อมูลแทนเพื่อนไม่ได้ เจ้าตัวจะเป็นคนอัปเดตของตัวเองจากหน้าโปรไฟล์ของเขาเอง
- ในหน้า **เพื่อนของฉัน** เรายังกดดูภาพรวมข้อจำกัดอาหารของกลุ่ม หรือจับกลุ่มเพื่อนที่ชอบอะไรคล้าย ๆ กันเก็บไว้เรียกดูวันหลังได้ด้วย

### 3. เทียบวันว่างของคนที่จะชวน (`วันว่างตรงกัน`)
- ด้านซ้ายให้ติ๊กเลือกเพื่อนที่จะชวนไปรอบนี้ (จะพิมพ์ชื่อหา หรือเลือกตามกลุ่มความชอบก็ได้)
- ด้านขวาเป็นปฏิทินที่ลงสีไว้ให้ดูง่าย ๆ:
  - **สีเขียวเข้ม** — ทุกคนที่เลือกว่างตรงกัน พร้อมเวลาที่เจอกันได้
  - **สีเขียวอ่อน** — ว่างบางส่วน (มีบางคนว่าง บางคนไม่ว่างหรือยังไม่รู้)
  - **สีแดง** — มีคนติดธุระ ไม่ว่าง
  - **สีเทา (ยังไม่ทราบ)** — เพื่อนคนนั้นยังไม่ได้แชร์ปฏิทินหรือยังไม่ได้ตั้งเวลาว่าง ระบบจะไม่เดาว่าว่างให้
- ส่วนเวลาว่างของเราเอง ตั้งได้ที่กล่อง **เวลาว่างของฉัน** ตรงมุมล่างซ้าย (เลือกตั้งแบบรายวัน หรือตั้งเป็นตารางประจำสัปดาห์ก็ได้)
- ถ้าอยากให้ดึงเวลาว่างจาก Google Calendar ให้กดไปเชื่อมที่หน้า **ตั้งค่า** ระบบจะดึงแค่ช่วงเวลาที่ว่าง/ไม่ว่างเท่านั้น ไม่เปิดเผยชื่อนัดหมายส่วนตัวให้ใครเห็น

### 4. สร้างนัดแล้วส่งลิงก์ให้เพื่อนตอบ (`กิจกรรม & คำชวน`)
- พอได้วันเวลาที่ลงตัว กด **สร้างกิจกรรมใหม่** แล้วใส่รายละเอียดนัด (ชื่องาน วันที่ เวลา สถานที่) พร้อมติ๊กเลือกเพื่อนที่จะชวน
- ระบบจะช่วยเช็กทั้งวันว่างและความชอบให้ รวมถึงเตือนไว้ก่อนด้วยถ้าในรายชื่อมีคนแพ้อาหารหรือข้อจำกัดด้านอาหารที่ต้องระวัง
- พอกดสร้างเสร็จ ระบบจะสร้างลิงก์เชิญเฉพาะตัวของแต่ละคนให้ กดคัดลอกส่งเข้าแชทไปให้เพื่อนได้เลย

### 5. เพื่อนกดตอบรับ และติดตามสรุป (`คำชวน & ตอบรับ` / `หน้าหลัก`)
- เพื่อนที่ได้รับลิงก์เปิดเข้าไปแล้วกดตอบได้ทันทีว่า **ไปด้วย** หรือ **ไม่สะดวก** (พร้อมบอกเหตุผลสั้น ๆ ได้) หรือถ้าเพื่อนล็อกอินแอปอยู่แล้ว ก็เข้าไปกดตอบรับจากหน้า **คำชวน & ตอบรับ** ได้เหมือนกัน
- หน้า **หน้าหลัก** จะสรุปภาพรวมให้ดูเร็ว ๆ ว่าเร็ว ๆ นี้มีนัดอะไรบ้าง ใครตอบรับแล้วบ้าง รวมถึงช่วยแนะนำแพลนกิจกรรมคร่าว ๆ สำหรับกลุ่มเพื่อนให้ดูเป็นไอเดีย

### 6. จัดการการแชร์และรีเซ็ตข้อมูล (`ตั้งค่า`)
ในหน้า **ตั้งค่า** มีไว้จัดการเชื่อมต่อ ปรับเลือกปฏิทิน หรือยกเลิกการเชื่อม Google Calendar รวมถึงเลือกเปิด-ปิดได้ว่าจะแชร์เวลาว่างให้เพื่อนคนไหนเห็นบ้าง และถ้าใช้บัญชีทดลองอยู่ สามารถกดปุ่ม **รีเซ็ตข้อมูลตัวอย่าง** เพื่อคืนค่าข้อมูลทั้งหมดกลับไปเหมือนตอนเริ่มต้นใหม่ได้ตลอด
